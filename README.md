# Aura Financial Voice Terminal

A low-latency, real-time financial voice agent querying audited SEC Form 10-K data with absolute deterministic accuracy using AssemblyAI Realtime and PGlite.

## Setup

Clone the repository:
```bash
git clone https://github.com/Maqsood32595/aura-financial-voice-terminal.git
```

Navigate into the directory and install dependencies:
```bash
cd aura-financial-voice-terminal
npm install
```

Start the application:
```bash
npm start
```
